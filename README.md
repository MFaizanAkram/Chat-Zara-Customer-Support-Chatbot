# 🛍️ Chat Zara — Customer Support Chatbot

## Problem
E-commerce businesses struggle to handle high volumes of repetitive customer queries efficiently. Traditional support systems are slow, costly, and inconsistent.

## Solution
Zara is an AI-powered customer support chatbot built on a Retrieval-Augmented Generation (RAG) pipeline. It retrieves the most relevant information from a curated knowledge base and generates accurate, context-aware responses — without hallucinating answers outside its domain.

## Impact
- Instant, 24/7 responses to customer queries
- Reduces load on human support agents
- Consistent and accurate answers for orders, refunds, payments, delivery, and account issues

## 🧰 Tech Stack
| Tool | Purpose |
|------|---------|
| Streamlit | Web UI |
| Groq (LLaMA 3.3-70B) | Language model inference |
| FAISS | Vector similarity search |
| Sentence Transformers | Text embeddings |
| Python Dotenv | API key management |
